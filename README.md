## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌍 **25+ Languages** | Translate between English, Spanish, French, Hindi, Japanese, Arabic, and many more |
| 🤖 **Auto Detect** | Automatically detects the source language |
| 🔊 **Text-to-Speech** | Listen to source text and translations using the Web Speech API |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari)
- Internet connection (for the translation API)

### Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_Language_Translation_Tool.git
   ```
2. Open the project folder:
   ```bash
   cd CodeAlpha_Language_Translation_Tool
   ```
3. Open `index.html` in your browser — **that's it!** No build tools, no npm, no setup.

## 📝 How It Works

1. **Enter Text** — Type or paste your text into the source panel
2. **Select Languages** — Choose source (or auto-detect) and target languages
3. **Translate** — Click the Translate button or press `Ctrl+Enter`
4. **Results** — View translation with confidence score, copy, listen, or download
5. **History** — Access past translations from the history section
